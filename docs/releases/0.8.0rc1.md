# Shadowseed Workbench 0.8.0 Release Candidate

This release line is intentionally separate from 0.7.2. It develops the next
product experience without changing the published 0.7.2 preview.

## Product direction

0.8.0 moves Shadowseed from a tester-oriented console toward a product that a
new user can understand, operate and verify without reading implementation
documentation first.

The product flow is:

**Start -> Run -> Observe -> Understand -> Verify -> Control -> Inspect**

## Included so far

- authority profiles: Controlled, Assisted, Autonomous and Open research;
- Controlled remains the backwards-compatible default;
- explicit persistence of the selected authority profile per run;
- authority-first onboarding;
- clearer visual hierarchy and reduced settings clutter;
- human-readable Shadow seed lifecycle cards;
- contextual manual interventions;
- raw JSON and audit events preserved under technical inspection;
- dedicated Verify surface for SSL-on / SSL-off attribution checks;
- in-product "What is Shadow Seed Learning?" explanation;
- documentation explaining SSL, its lifecycle and its distinction from
  fine-tuning.

## Planned before final 0.8.0

- file/text upload as a first-class run input;
- text extraction and chunking;
- corpus-scale observation and aggregation;
- Assisted runtime automation;
- Autonomous runtime automation while preserving Gate and audit semantics;
- richer progress and corpus summaries;
- regression proof that Controlled matches the current production behavior.

## Claim boundary

SSL accumulates an external, inspectable experience layer. It does not retrain
the base model weights. More text is not automatically better: corpus-scale use
depends on deduplication, clustering, provenance, contradiction handling, decay
and selective surfacing.

This is a release candidate line, not a production-ready claim.
