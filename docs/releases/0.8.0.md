# Shadowseed Workbench 0.8.0

Shadowseed Workbench 0.8.0 is the first product-oriented release of the
Shadow Seed Learning experience layer. It keeps the base model unchanged while
making shadow memory, authority, verification and source ingestion usable from
one local Workbench.

## Highlights

### Product experience

- authority-first onboarding with Controlled, Assisted, Autonomous and Open research;
- dedicated Chat, Sources, Shadow, Verify, Control and About SSL surfaces;
- plain-language seed lifecycle explanations with raw JSON and audit events still available;
- layered in-product explanation of what Shadow Seed Learning is and is not;
- clearer run status showing the selected authority profile and effective Validation Gate.

### Authority runtime

- Controlled remains the backwards-compatible default on the live evidence-backed Gate;
- Assisted keeps authority evidence-backed and raises review requests when mature recurrence
  still needs independently verified support;
- Autonomous and Open default to the existing exploratory Gate, where recurrence may raise
  authority without being relabeled as external evidence;
- promotion still occurs only through the canonical Validation Gate;
- later influence still requires relevance and the existing point-of-use safety contract;
- explicit Gate overrides remain available for compatibility and research callers;
- profiles never invent machine evidence. Any future system-evidence producer must be explicit,
  attributable and accepted by policy.

### Source ingestion

- first-class Sources workspace for pasted text and multiple files;
- supported file types in 0.8.0: TXT, Markdown, JSON and CSV;
- auditable chunk provenance;
- source chunks enter Shadowseed as non-chat observations rather than fake conversation turns;
- uploaded text is observation input, not trusted evidence;
- corpus summaries expose new seeds, promotions and Assisted review needs.

### Verification

- paired SSL-on / SSL-off comparison support;
- explicit attribution checks based on whether a seed actually surfaced;
- Shadow inspection for lifecycle state, Gate decisions, contradictions and influence events.

## What SSL is

Shadow Seed Learning is an external, inspectable experience layer around an LLM.
It observes possible missing perspectives, lets those perspectives earn or lose
authority over time, and selectively reintroduces authorized perspectives when
they become relevant later.

It does not retrain the base model weights.

## Release boundaries

0.8.0 does not yet include:

- PDF or DOCX ingestion;
- asynchronous large-corpus progress, cancel or resume;
- an auditable machine-evidence producer;
- automatic contradiction resolution.

Those remain follow-up work. Their absence does not change the authority boundary:
the Validation Gate and point-of-use checks remain the only path to influence.

## Upgrade note

0.8.0 supersedes the 0.7.2 research preview for the Workbench product line.
Existing 0.7.2 behavior remains represented by the Controlled profile.
