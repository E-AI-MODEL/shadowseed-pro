# Two-moment, 48-response exploratory inquiry pilot (28 October 2026)

**Status at preregistration:** source-replayed and offline-tested. No claim of Q1/Q2 success, G0 approval or new human ratings.

## Question

Can a previously recorded, weight-zero detector candidate make a *different subsequent research question* accessible, beyond ordinary generation, deliberate independent search and equally prominent irrelevant candidate text?

This is a narrow **research contrast**, not a proof that any LLM never could have formed a relation, and not a full product Shadowseed Gate experiment. The literal [two-part foundational thesis](../../docs/research/possibility-space-thesis.md) remains unchanged.

## Factors and budgets

| Factor | Levels |
|---|---|
| Research checkpoint | 2, both from **one** case |
| Research arms | Ordinary; deliberate independent search; target candidate (weight 0); unrelated placebo candidate |
| Independent repeated requests | 3 per arm and checkpoint; sampling variation is not guaranteed |
| Later inquiry turns | 2 sequential turns per trajectory |
| Planned/model-call hard cap | **2 × 4 × 3 × 2 = 48** provider model-call attempts |
| Provider input | Fixed original context within each model/checkpoint; note only in the candidate/placebo arms |
| Model IDs | `gpt-5-2025-08-07` and `gpt-6-luna`, NEVER pooled as a matched same-model comparison |
| Hard tokens | 360,000 reported input+output tokens total; conservative pre-request cutoff |
| Max output | 1,900 tokens per call |
| Reattempt | Zero. Partial, failed, timed-out and incomplete runs are not counted as null effects |
| Human assessments | **0 at run time**; independent blind semantic review remains a follow-up |

Four arms are compared **within** each model/checkpoint. The two model checkpoint outcomes are not used to claim one model has deeper doubt than the other. All calls use `store=false`; the source artifact is read with a short-lived GitHub token. The original source and owner-unblind records are not committed to the public repo.

## Interpretation and anti-circularity

1. **Q1 accessibility:** Did ordinary and deliberate independent search generate the content of a candidate relation, or a meaning-equivalent relation? This is an *observed sampling contrast*, not proof of impossibility.
2. **Q2 two-turn development:** Did the first proposed research question lead to a genuinely different, falsifiable further question in the next turn, beyond paraphrase? Exact candidate echo is not a success.
3. **Alternative explanations:** Prompt conditioning, relevance, extra text, model sampling differences and restricted sample sizes are explicit rivals. Placebo, ordinary and deliberate-search arms are all necessary.
4. **Permissive exploration vs user authority:** The study may expose a weight-zero candidate in a *research inquiry prompt*. It does not promote it in the production Gate, authorize it to affect a user-facing product answer, or change product defaults.
5. **Negative outcome:** A model correctly saying there is no justified new question is acceptable; forced novelty is not automatically a benefit.
6. **Technical validity:** Horizon geometry and battery hardware are hypothetical in the fictitious case. Source-grounded feasibility must be judged separately from whether a relation was generated.

### Reviewer questions (blinded packet)

- Is a distinct later relation or condition actually articulated, or only restated?
- Can it be operationalised as a test that could rule it out?
- Is the claim internally warranted by the supplied observations, or does it require invented measurements?
- Was the substantive relation already present in the original model answer or before the checkpoint?
- Is the subsequent test meaning-equivalent to other tracks?

Report counts, paired examples, raw uncertainty and disagreements, not a single unexplained efficacy percentage. No 95% confidence claim from two checkpoint families with three repetitions.

## Privacy and release boundary

The workflow uploads **only a machine-readable public aggregate summary** and a private-result bundle encrypted to a one-off **3072-bit RSA public key** (see `research/keys/two-point-20261028-public.pem`). Its matching RSA private key is held **outside GitHub**, in the author's working environment. The bundle includes observed responses, the randomized blind packet and an owner-only mapping; only the author holding the private key can extract it. The public repository does not contain the original artifact, an API key, unencrypted responses, owner-unblind mappings or private key.

Encryption uses a fresh random 256-bit passphrase, OpenSSL AES-256-CBC with PBKDF2 and RSA-OAEP-SHA256 to protect that passphrase; retain artifact hash and source-check receipts for integrity. This scheme protects confidentiality in a public repository but is not an institutional research archive.

Do **not** trigger or rerun the paid workflow on ordinary pushes: a one-shot branch+path and fixed-before-commit check plus `github.run_attempt == 1` are required. The public manuscript remains exploratory pending human review; this trial cannot settle the original full thesis.
